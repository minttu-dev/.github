# Minttu

Minttu is an open source classless-first CSS design system and web toolkit.
Fluid typography with musical interval ratios, adaptive color systems, responsive
layout primitives, and progressively enhanced components — beautiful, accessible
HTML without requiring classes.

Governed by the [Omnifi Foundation](https://omnifi.foundation).
